# Якість і автоперевірка

## Що вимірює `pipeline/qa.py` (без участі моделей)
| Перевірка | Норма | Чому |
|---|---|---|
| Тривалість | сума слотів сценарію ± 0,25 с | озвучка й кліпи рахуються за слотами |
| Розмір і частота | 1080×1920, 30 кадр/с | Reels/Shorts |
| Звук | 48 кГц, стерео | вимога платформ |
| Гучність | −16,5 … −12,5 LUFS (ціль −14) | `loudnorm` у рендері |
| Пік | ≤ −1 dBFS | без кліпінгу |
| Чорні кадри | немає (крім фінального затемнення) | помилка склейки |
| Завмерлі кадри (`freezedetect`) | немає | нерухомий кліп = глюк або нудно |
| Паузи в звуці > 1,2 с | немає | щільна подача; голос Edge TTS робить ≈1 с паузу після крапки — з'єднуйте речення комами й тире |

Зауваження не зупиняють чернетку, але їх треба показати людині. `--no-vision` лишає лише вимірювання (огляд кадрів моделлю йде окремим кроком на Kaggle).

## Автоперевірка AI-кліпів (глюки морфінгу)
- **Стрибок між сусідніми кадрами:** відношення макс/медіана різниці сусідніх кадрів (зменшена копія 96×170, градації сірого) > 5 → підозра на різку зміну.
- **Кореляція першого й останнього кадру** < 0,3 — кліп «розплився»; для сильного наїзду камери це нормально, тож це лише привід глянути.
- **Перший кадр кліпу ≈ стартовий кадр** (кореляція ≈ 1,0) — підтверджує, що модель стартувала з потрібного зображення.
- Остаточне слово про глюки — за людиною: автоматика їх не бачить повністю.

## Що показати людині на затвердження
1. Сценарій по таймінгах (до озвучки й кліпів).
2. Прев'ю озвучки (mp3) — наголоси.
3. Музика (mp3).
4. Чернетка 720p + веб-розкадровка (мініатюри кліпів, джерела).
5. Зауваження автоперевірки одним рядком.

## Типові правки й їхня ціна
| Правка | Ціна |
|---|---|
| Слово з хибним наголосом | 2 хв (словник + перегенерація озвучки + рендер 15 хв) |
| Інша музика | 25 хв GPU + рендер |
| Замінити один кліп | ≈22 хв GPU + рендер |
| Інший голос | озвучка + рендер (відеоряд не чіпається) |
| Змінити текст | озвучка, слоти, **кліпи кадрів, що змінилися**, рендер — тому сценарій затверджують першим |
