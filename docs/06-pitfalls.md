# Пастки, на які вже наступили (жовтень 2026)

## Озвучка
- **Мультимовні голоси Microsoft** (Andrew/Brian Multilingual) для української через `edge-tts` повертають порожнє аудіо. Використовуйте `uk-UA-OstapNeural` (чол.) або `uk-UA-PolinaNeural` (жін.).
- **Наголоси:** знак U+0301 сервіс виконує ненадійно → словник вимови (альтернативне написання лише для озвучки) і прослуховування людиною. Варіанти слова генеруйте пачкою («варіант один… п'ять»).
- **Паузи:** ≈ 1 с після крапки. З'єднуйте речення комами/тире; слоти кадрів рахуйте за межами слів, а не за mp3 (там тиша на початку й у кінці).
- **Ліцензія голосу:** `edge-tts` — клієнт (LGPL-3.0) до онлайн-сервісу Microsoft; окремої ліцензії на комерційне використання згенерованого аудіо немає.
  Для монетизації перезапишіть голос через Piper TTS (MIT), Azure Speech за договором або живого диктора — відеоряд при цьому не чіпається.
- **Gemini API** (текст, TTS, картинки) може віддавати 429 «monthly spending cap» — ліміт знімається в AI Studio; конвеєр без нього працює.

## Музика
- **ACE-Step не вміє українського вокалу** (дикція «пливе»): лише інструментал. Пісня зі словами — Suno/Udio (платний план для комерції) або живий вокал.
- **Content ID:** навіть записи класики з CC0 ловлять хибні претензії → власна/згенерована музика безпечніша. Треки CC BY (Kevin MacLeod) — з підписом і ризиком претензій.
- Kaggle GPU **T4 не вміє bfloat16** (`unable to find an engine`) → `float32`. Окреме середовище `uv venv -p 3.11`: у ядрах Python 3.13, а `ace-step` потребує < 3.13.
  Закріпіть `torch==2.5.1 torchaudio==2.5.1 torchvision==0.20.1` (новіший torchaudio зберігає wav лише через torchcodec).

## Kaggle
- **Верифікація телефоном обов'язкова** (без неї немає GPU й інтернету в ядрах).
- Датасет монтується за різними шляхами (`/kaggle/input/datasets/<user>/<slug>/…`) → шукайте файли `rglob`, не вгадуйте шлях.
- Нова версія датасету доступна не одразу → чекайте `datasets status`; API інколи віддає **403 на GetDatasetStatus** — тоді чекайте 2 хв і продовжуйте (це вже є в `kaggle_job.py`).
- `kaggle datasets create --private` не підтримується новим CLI (датасети й так приватні).
- Windows: CLI падає на кодуванні cp1251 після завантаження результату → `PYTHONUTF8=1` (файли вже на диску, помилку можна ігнорувати).
- Шрифтів із кирилицею в ядрі немає → кладіть Noto Sans у пакет (`pipeline/fonts/`).
- Логін Kaggle не вписуйте в код: пуш у чужий простір імен заборонений.
- Одна задача відео = один запуск Kaggle; для черги потрібен цикл, що чекає звільнення «вікна» (`clip_queue.py` запускає по одному).

## Футаж
- **YouTube** блокує IP після кількох десятків запитів `yt-dlp` (`HTTP 429`, «confirm you're not a bot»); cookies свого акаунта не використовуйте без явного рішення власника.
- **Pexels API** тимчасово не видає нові ключі; **Pixabay** працює, але сток програв AI-кліпам під фрагменти (брали «гроші», а не «Бреттон-Вудс»).
- **Wikimedia Commons:** для відео про економіку майже нічого; для **зображень** (стартові кадри) — найкраще джерело. Шукайте по категоріях і конкретних назвах; повнотекстовий пошук приносить сміття; після кількох запитів поспіль — 429.
- Огляд стокових кадрів моделлю виявив російські рублі в кліпах «грошей» → завжди пишіть, чого не показувати.

## Агенти
- **Hermes повільний** (крок 15–80 с) і має ліміт 180 с на команду: допоміжні скрипти мусять бути швидкими (паралельні запити), інакше агент витрачає години.
  Не вірте позначці «перевірено кадрами» від моделі без «очей».
- **Cursor `ask`** не має веб-пошуку; місячний ліміт підписки може вимкнути окрему модель (`auto` працював).
- Транскрипти розмов у Windows можуть зберігати кириличні промпти зіпсованими — не покладайтесь на них як на джерело запитів.

## Windows
- Python не розуміє MSYS-шляхів `/c/Users/...` з Git Bash у `subprocess` → передавайте `C:\Users\...`.
- Фонові процеси з сесії Claude Code гинуть при її перезапуску → запускайте окремо (`Win32_Process.Create`).
- Не множте фонові процеси: кожна сесія Claude запускає свої мости до агентів; 6 сесій = ≈ 50 процесів `node` і 2 ГБ RAM. Закривайте зайві сесії.

## AI-кліпи
- Завмерлі кадри в окремих кліпах — норма, автоперевірка їх знаходить; замініть кліп або додайте рух у промпті.
- Стартові кадри широкого формату (банкноти, картини) → картка на розмитому тлі, щоб H3 не обрізав суть.
- У промпті руху завжди: «Keep … stable, no morphing, no text» — зменшує розпливання й вигадані написи.
