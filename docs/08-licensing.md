# Ліцензії й етика

| Складова | Ліцензія / умови | Що робити |
|---|---|---|
| Стартові кадри (Wikimedia Commons) | суспільне надбання, CC0, CC BY, CC BY-SA (позначається окремо) | `commons_fetch.py` відбирає лише ці; автор і ліцензія пишуться в `plan_resolved.json` і в `final_credits.txt` — вставте в опис |
| AI-кліпи (MiniMax H3) | перевірте умови ваг на сторінці моделі (Hugging Face) для комерційного використання | зазначайте «згенеровано ШІ» |
| Музика ACE-Step v1 | Apache-2.0 | підпис «music generated with ACE-Step» |
| Озвучка Edge TTS | безкоштовний онлайн-сервіс Microsoft, окремої ліцензії на комерцію немає | для монетизації — Piper (MIT), Azure за договором або диктор |
| Noto Sans (шрифти) | SIL Open Font License | можна поширювати з репозиторієм |
| Стоки Pixabay | Pixabay Content License (комерційно можна, без атрибуції) | перевірте актуальні умови |
| YouTube CC BY | CC BY; завантаження обмежене правилами платформи | лише як доповнення, без масового скачування |

Платформи (YouTube, TikTok, Instagram) вимагають позначати синтезований і реалістичний згенерований контент; масові шаблонні відео без унікального
змісту не монетизуються. Тому: унікальний сценарій і кліпи на кожен ролик, людина бачить і схвалює випуск, публікація лише через офіційні API.
Не імітуйте реальних людей і не видавайте згенероване за документальне.
