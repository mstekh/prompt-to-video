Відео з одного промпта

Ви пишете Claude Code тему ролика, а він сам пише сценарій, озвучує його, генерує AI-кліпи й музику на безкоштовному GPU Kaggle, монтує вертикальне відео 9:16 з субтитрами і перевіряє якість. Ваша робота займає ≈15 хвилин: затвердити сценарій, послухати наголоси й музику, дати правки.

0 грнпонад підписку Claude: Kaggle, Edge TTS і Wikimedia Commons безкоштовні
≈1 годперше налаштування, один раз
≈4–8 год GPUна ролик 60–100 с (квота Kaggle ≈30 год на тиждень)
9:16, 1080pReels, Shorts, TikTok; озвучка українською

Ви — дії, які робить людина. Claude — дає промпт, решту Claude Code робить сам. GPU — витрачає квоту Kaggle.

5Три короткі затвердження

Ви
  1. Сценарій. Claude показує таблицю «час → текст → напис». Відповідаєте «так» або правки. Це найдешевше місце для змін: після кліпів кожна правка коштує годин GPU.
  2. Наголоси. Слухаєте mp3 озвучки й називаєте слова з неправильним наголосом. Claude додає їх у словник вимови.
  3. Музика. Слухаєте варіант (≈25 хв GPU на кожен) і кажете «ок» або «інший настрій».

6AI-кліпи на Kaggle

Claude GPU

Для кожного фрагмента Claude шукає стартовий кадр на Wikimedia Commons і «оживлює» його моделлю MiniMax H3 на GPU Kaggle: ≈22 хв на кліп 5 с. 12 кліпів займуть ≈4,5 години; комп'ютер у цей час вільний для інших справ, лише не закривайте Claude Code.

Квота Kaggle — близько 30 годин GPU на тиждень. Якщо робите кілька роликів, просіть Claude запускати їх по одному.

7Розкадровка і прибирання глюків

Claude

AI-кліпи часто виглядають «по-кіношному», а не як у житті. Автоматичні вимірювання таких глюків не бачать, тож кожен кліп розкладається на кадри і переглядається очима: pipeline/clip_sheets.py.

  • Фізика техніки: у квадрокоптера немає ракетних прискорювачів, полум'я під дроном означає глюк.
  • Розміщення й масштаб: дрони впритул, важка техніка на висоті людини, машини «пливуть» травою.
  • Поза сценою: студія чи порожнє тло посеред дії.
  • Морфінг і написи: обличчя «пливуть», вежі зникають, з'являються вигадані літери й чужі прапори.
Промпт для Claude: перевірити кліпи (якщо треба окремо)
Зроби крок 9б рецепту для проєкту projects/[назва]: розклади всі кліпи на кадри (pipeline/clip_sheets.py, потім --detail для кожного),
переглянь кожен аркуш і знайди нереалістичне: фізику техніки, щільність і масштаб, кадри поза сценою, морфінг, написи.
Запиши рішення в work/ai_clips/review.md (лишити / обрізати / замінити / перегенерувати і чому).
Покажи мені аркуші прибраних кліпів і причину одним рядком. Перегенеровуй лише після мого «ок».
Перевірено на ролику-битві: з 7 кліпів прибрали 3 (ракетне полум'я під коптером, рій впритул, кадр поза битвою). Коротший ролик із 4 правдоподібних кліпів вийшов кращим.

8Чернетка, правки, фінал

Claude Ви

Claude збирає ролик на Kaggle (≈15 хв, без GPU), автоматично перевіряє розмір, гучність, завмерлі й чорні кадри і показує чернетку 720p. Ви кажете правки, потім Claude робить фінал 1080×1920 і текст опису з джерелами кадрів і позначкою «озвучка синтезована, відео згенеровано ШІ».

?Якщо щось не так

  • Kaggle: «GPU недоступний» або немає інтернету в ядрі — не підтверджено телефон в акаунті.
  • Голос ставить наголос не туди — назвіть слово Claude, він додасть написання для озвучки в lexicon.json.
  • Кліп не відкривається — Kaggle віддав сторінку помилки замість відео; Claude перезапустить цей кліп.
  • Скінчилась квота GPU — нова з'явиться наступного тижня; готові кліпи не пропадають.
  • Всі пастки, на які вже наступили: docs/06-pitfalls.md.
