# Готові брифи для агентів (копіюйте й підставляйте)

Бриф — єдине, що модель знає. Чим точніший, тим менше правок. Усі брифи просять **компактну** відповідь, яку Claude Code читає без зайвих токенів.

## Сценарій (сильна модель)
```
Ти сценарист навчальних відео для [АУДИТОРІЯ: напр. студентів; щільно, точно, з термінами й короткими поясненнями; не для дітей].
Тема: [ТЕМА В ОДНОМУ РЕЧЕННІ]. Мова: українська. Тривалість: ~[N] с = ~[слів] слів (темп ≈ 2,3 слова/с).
Структура: 9 кадрів S1..S9, кожен 18–28 слів. S1 — хук-питання, S9 — висновок.
Обов'язково згадати: [ФАКТИ, ДАТИ, ТЕРМІНИ].
Чого уникати: [напр. політичні гасла, назви брендів, цифри арабськими].
Вимоги до мови: усі числа й роки СЛОВАМИ («тисяча дев'ятсот сімдесят першого»); без абревіатур («Сполучені Штати», не «США»);
без латиниці; нормативні форми («взялися», «обмінювалися»); живий упевнений тон; лише факти, у яких ти впевнений.
Відповідь ЛИШЕ JSON: [{"id":"S1","text":"...","label":"КОРОТКИЙ НАПИС"}, ...]
```

## Фактчек (модель іншого сімейства, без веб-пошуку позначає UNVERIFIED)
```
Ти фактчекер. Для КОЖНОГО твердження сценарію (нижче): «так / неточно / хибно» + коротка поправка, лише там, де потрібна.
Окремо: русизми, кальки, неприродні для усної української фрази; слова, які синтезатори типово озвучують із хибним наголосом
(напиши слово з позначеним наголосом). Не більше 200 слів. Без вступів.
[ТЕКСТ СЦЕНАРІЮ]
```

## План кліпів (сильна модель)
```
Для кожного з кадрів сценарію (нижче) запропонуй по 2–3 кліпи. Для кожного: id (S2a, S2b…), shot, q — запит до Wikimedia Commons
англійською (реальний об'єкт, місце чи подія, з суспільного надбання), subj — що має бути видно, prompt — опис руху для image-to-video
англійською: повільний рух камери або природний рух об'єктів; обов'язково закінчи «Keep faces and objects stable, no morphing, no text.»
Не вигадуй файли — лише запити. Без людей у сучасних кадрах і без брендів. Відповідь ЛИШЕ JSON-масивом.
[СЦЕНАРІЙ З КАДРАМИ]
```

## Пошук футажу/дослідження (агент із веб-доступом, напр. Hermes)
```
Знайди безкоштовні сервіси з API (безкоштовний рівень, комерційне використання?) для [ПОТРІБНЕ]. Для кожного: назва, посилання,
ліміти цифрами, API так/ні, ліцензія. Лише те, що знайшов у вебі, біля кожного факту — URL; решту познач UNVERIFIED. Результат у файл research/*.md.
```
Порада: агентам з повільними кроками (десятки секунд) давайте **готові швидкі скрипти** й чіткий формат виходу; не просіть їх «оцінити картинку»
— без «очей» вони вигадують «перевірено кадрами».

## Огляд кадрів (візуальна модель на Kaggle)
`pipeline/kaggle_review.py` + `review_kernel.py` (Qwen2.5-VL-3B) для кожної сцени повертає JSON: `match` 0–10, `quality`, `text_or_watermark`,
`faces_closeup`, `motion_ok`, `desc`. Для стоку поріг відбору `match ≥ 5`; для AI-кліпів зі стартових кадрів — беріть усі, відсіюйте лише очевидно хибні.
