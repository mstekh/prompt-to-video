# Промпт: з чого все починається

Один промпт до Claude Code запускає весь процес. Нижче шаблон, приклад, що в ньому важливо й чого уникати.

## Шаблон
```
Зроби навчальне відео для Reels/Shorts за рецептом docs/03-step-by-step.md.
Тема: [одне речення: про що відео і яке питання воно закриває].
Аудиторія: [хто дивиться і їхній рівень].
Мова й голос: [українська; упевнений чоловічий голос].
Настрій музики: [спокійна | тривожна | динамічна].
Тривалість: [до 100 с]. Склейки кожні [2–3 с].
Обов'язкові факти: [події, дати, терміни, які мають прозвучати].
Чого уникати: [що не говорити й не показувати].
Візуал: унікальні AI-кліпи під кожен фрагмент тексту; стартові кадри лише з суспільного надбання/CC.
Спершу покажи сценарій по таймінгах і чекай «так». Далі працюй сам; чернетки — 720p; у кінці — звіт токенів і джерел.
```

## Приклад, з якого зроблено перший ролик
```
Тема: чим забезпечена валюта сьогодні, якщо вона не обмінюється на золото.
Аудиторія: студенти; щільно, з термінами, без дитячих прикладів.
Мова й голос: українська; упевнений чоловічий голос.
Настрій музики: спочатку спокійна, потім варіант тривожної.
Тривалість: до 100 с. Склейки кожні 2–3 с.
Обов'язкові факти: золотий стандарт, Бреттон-Вудс 1944, 15 серпня 1971, фіатні гроші, закон і податки, створення грошей банками, гіперінфляція (Німеччина 1923, Україна 1993).
Чого уникати: російські купюри, чужі логотипи, політичні гасла.
```

## Що робить промпт сильним (уроки першого ролика)
1. **Назвіть аудиторію й рівень.** Без цього текст виходить «дитячим» («ти мені зерно, я тобі глечик») — замовник забракував першу версію саме за це.
2. **Перелічіть факти, які мають прозвучати.** Інакше модель обере безпечні банальності. Факти потім перевіряє друга модель.
3. **Одразу скажіть, чого не показувати.** Наш огляд кадрів знайшов у стокових кліпах російські рублі в ролику про гривню.
4. **Задайте настрій музики.** Спокійну й тривожну варто порівняти на слух — це 25 хв GPU на варіант.
5. **Вимагайте показати сценарій до роботи** — переробка після кліпів коштує годин GPU.
6. **Просіть 720p-чернетки й звіт токенів** — легше й швидше; повну якість лише для фіналу.
7. **Не просіть «як відомий ролик/пісня».** Лише настрій: інакше ризик плагіату й порожнього результату.

## Антишаблони
- «Зроби гарне відео про гроші» — без аудиторії, фактів і тривалості.
- Числа цифрами в тексті озвучки (синтезатор плутає «двадцять»/«двісті»).
- Вимога вокалу українською від ACE-Step (див. [06-pitfalls.md](06-pitfalls.md)).
- Масовий пошук на YouTube з одного IP (тимчасове блокування за кілька десятків запитів).
